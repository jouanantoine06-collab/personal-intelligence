# Roadmap indicative

- **V0.1 — Noyau** : conversation textuelle, identité, mémoire explicite (confirmation obligatoire), un outil simple, confirmation générique, journal d'audit.
- **V0.2 — Voix** : speech-to-text, text-to-speech, interruption, latence acceptable. Introduit probablement un premier écart au modèle synchrone (connexion temps réel).
- **V0.3 — Outils personnels** : email (lecture + brouillon), calendrier, tâches, notes, fichiers. Premier terrain réel pour envisager un modèle `Plan`.
- **V0.4 — Vision** : photos, documents, caméra. Premier terrain réel pour envisager un `Knowledge Engine`.
- **V0.5 — Contexte et projets** : approfondissement du Context Engine, continuité avancée.
- **V0.6 — Desktop** : introduit un deuxième client actif — nécessite de trancher la clé d'identité du Context Engine (utilisateur seul vs utilisateur+device).
- **V0.7 — Mobile**.
- **V0.8 — Compétences** : SDK de compétences, première compétence spécialisée (potentiellement automobile/Verdict).
- **V0.9 — Proactivité**.
- **V1 — Intelligence personnelle utilisable** : cohérence multi-appareil, mémoire contrôlable, outils essentiels, voix, vision, sécurité, expérience stable.

Chaque phase ne s'ouvre que lorsqu'un cas d'usage réel l'exige — pas par anticipation (principe d'architecture n°10).
